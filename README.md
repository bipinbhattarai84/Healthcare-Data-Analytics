🏥 Healthcare Data Analytics Dashboard (Power BI)

This project focuses on healthcare data analytics using Power BI. The goal is to enable data-driven decision-making for healthcare service providers by analyzing patient visits, departmental performance, billing, treatment costs, and insurance metrics.

📊 Project Objective

To identify trends and patterns in patient visits, departmental performance, machine usage, and billing to support better resource allocation, financial planning, and service optimization in healthcare organizations.

🔧 Tools & Technologies

•	Power BI – Dashboard creation, KPIs, measures, and data modelling

•	Public Healthcare Dataset – De-identified patient and billing data

📁 Key Dashboards & KPIs

The Power BI report includes the following dashboards and insights:

1. Departmental & Doctor Visits
   
•	Most visited departments based on patient volume

•	Doctor-wise visit analysis

•	Billing segmented by department


2. Machine Usage Analysis
   
•	Most used diagnostic machines (e.g., X-Ray, MRI)

•	Machine utilization trends over time

3. Year-to-Date vs Previous Year-to-Date
•	Visits (YTD vs PYTD) by month
•	Billing amount trends (YTD vs PYTD)

4. Financial Metrics & KPIs
   
•	YTD Billing Amount

•	Average Billing per Visit

•	Medication Cost (Total & Avg)

•	Treatment Cost (Total & Avg)

•	Insurance Coverage (Total & Avg)

•	Out-of-Pocket Cost per Person (Total & Avg)

🏁 Outcome

This dashboard allows stakeholders to:

•	Track healthcare performance metrics in real time

•	Identify underperforming departments or high-cost areas

•	Make informed decisions based on financial and operational data

•	Improve service efficiency and cost management
